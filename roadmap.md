# Physics MCQ Examination Portal — Roadmap

Design direction: "Lab Notebook" (approved).
Backend: Lovable Cloud (Postgres + Auth), server-side logic via TanStack server functions.

## Phases
- [ ] P1 Database schema + RLS + grants + roles
- [ ] P2 Auth: teacher email login, student Login ID login, first-admin bootstrap, password change/reset
- [ ] P3 Student & class management (create/edit/disable/archive/reset password)
- [ ] P4 Chapters + topics
- [ ] P5 Question bank (CRUD, filters, server-side pagination, CSV import, KaTeX)
- [ ] P6 Test builder (config + question selection/reorder)
- [ ] P7 Assignment (student / class / section)
- [ ] P8 Student portal + exam interface (navigator, randomization)
- [ ] P9 Autosave + server-authoritative timer + attempt restore
- [ ] P10 Server-side scoring, instant result, result history, teacher results + export
- [ ] P11 Analytics (teacher + student)
- [ ] P12 Audit logs + security hardening
- [ ] P13 README / docs
